**Not a Competing Use:**

### Why BSL?

We want the code to be open and auditable (no black-box trust required), while protecting the commercial model that funds continued development. BSL lets us publish everything — schemas, engine, audit logic — so buyers can inspect every line, while preventing a cloud provider from wrapping it and selling it as their own product.
